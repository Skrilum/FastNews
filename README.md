# FastNews — Новостной портал

Стек: HTML5, CSS3 (Flexbox), JavaScript (Vanilla), Node.js + Express, MongoDB.

---

## 📋 Требования для запуска

Перед запуском убедитесь, что установлено:

1. **Node.js** (версия 18 или выше) — https://nodejs.org
2. **MongoDB Community Server** — https://mongodb.com
3. **VS Code** с расширением **Live Server** (или любой другой способ поднять локальный веб-сервер на порту 5500)

Проверить установку Node.js:

```bash
node -v
npm -v
```

## 🚀 Инструкция по запуску

### Шаг 1. Установить зависимости

Откройте терминал в папке проекта и выполните:

```bash
npm install
```

### Шаг 2. Запустить MongoDB

**Вариант A — MongoDB установлена локально.**

Откройте **новое окно терминала** (не закрывайте его) и выполните:

```bash
mongod --dbpath C:\mongodb-data\db
```

Путь `C:\mongodb-data\db` можно заменить на любой другой, где MongoDB будет хранить данные. Папка должна существовать и быть пустой.

Если MongoDB установлена как служба Windows, она запускается автоматически при старте системы — тогда этот шаг можно пропустить.

**Вариант B — использовать MongoDB Atlas (облачная бесплатная БД).**

1. Зарегистрируйтесь на https://mongodb.com
2. Создайте бесплатный кластер (M0)
3. Получите строку подключения вида `mongodb+srv://user:password@cluster.mongodb.net/fastnews`
4. В файле `.env` замените `MONGODB_URI` на эту строку

### Шаг 3. Наполнить БД тестовыми новостями (один раз)

```bash
node seed.js
```

или

```bash
npm run seed
```

Вы увидите:

```text
✅ Подключено к MongoDB
🗑️ Старые новости удалены
✅ Добавлено 12 новостей
🔌 Соединение закрыто
```

### Шаг 4. Запустить бэкенд

В терминале из папки проекта:

```bash
node server.js
```

или

```bash
npm start
```

Должно появиться:

```text
✅ MongoDB connected
🚀 Сервер запущен на http://localhost:5000
```

**Не закрывайте этот терминал** — сервер должен работать, пока вы проверяете приложение.

### Шаг 5. Открыть фронтенд

**Важно:** фронт должен быть открыт именно на `http://localhost:5500`, а не на `127.0.0.1:5500` — иначе куки авторизации не будут отправляться.

**Способ 1 (через VS Code):**

1. Откройте папку проекта в VS Code.
2. Правой кнопкой по `index.html` → **Open with Live Server**.
3. В адресной строке браузера убедитесь, что адрес `http://localhost:5500/index.html`. Если `127.0.0.1` — замените на `localhost` вручную.

**Способ 2 (через npx):**

```bash
npx http-server -p 5500
```

Затем откройте `http://localhost:5500/index.html`.

## 🧪 Как проверить функциональность

### Гость (без входа)

1. Откройте главную страницу — должны отобразиться новости, сгруппированные по секциям (Спорт, Кино, Технологии, Авто).
2. Кликните на любую новость — откроется страница новости. Видны: заголовок, автор, дата, рубрика, счётчик просмотров, комментарии.
3. Перезагрузите страницу новости — счётчик просмотров увеличится (например, было 5, станет 6).
4. Под комментариями видна надпись «🔒 Только авторизованные пользователи могут оставлять комментарии» — формы нет.

### Регистрация

1. Нажмите «Войти» → «Зарегистрироваться».
2. Введите имя, email, пароль. Нажмите «Зарегистрироваться».
3. Появится сообщение «✅ Регистрация успешна».

### Авторизация и комментирование

1. Войдите с тем же email и паролем.
2. Кнопка «Войти» сменилась на «👤 Имя» + появилась ссылка «Выход».
3. Откройте любую новость — теперь форма комментариев видна.
4. Оставьте комментарий — он появится в списке с вашим именем и текущей датой.

### Выход

1. Нажмите «Выход».
2. Кнопка вернулась к «Войти», форма комментариев снова скрыта.

## 🛠️ Возможные проблемы

| Проблема                                                    | Решение                                                                                             |
| :---------------------------------------------------------- | :-------------------------------------------------------------------------------------------------- |
| `❌ MongoDB connection error`                               | Проверьте, что MongoDB запущена (см. Шаг 2). Проверьте строку подключения в `.env`.                 |
| Куки не сохраняются / сбрасывается авторизация при переходе | Убедитесь, что фронт открыт на `http://localhost:5500`, а не `127.0.0.1:5500`.                      |
| Порт 5000 занят                                             | В `.env` измените `PORT` на другой (например, 5001) и в `app.js` в переменной `API_URL` тоже.       |
| Порт 5500 занят                                             | В Live Server настройте другой порт, но тогда добавьте его в массив `allowedOrigins` в `server.js`. |
| `npx http-server` не работает                               | Установите http-server глобально: `npm install -g http-server`.                                     |
| Новости не отображаются                                     | Убедитесь, что `node seed.js` выполнен успешно.                                                     |

## 📌 Технические детали

- **Авторизация:** JWT в `httpOnly` cookie. Токен живёт 7 дней.
- **Хеширование паролей:** bcryptjs.
- **Счётчик просмотров:** увеличивается на сервере при GET `/api/news/:id`.
- **Секции новостей:** Технологии, Авто, Спорт, Кино.
- **Группировка:** на бэкенде (фильтр `?section=`) и на фронте (в `app.js` → `loadNews`).
- **Адаптивность:** медиа-запросы на 992px, 768px, 480px.
